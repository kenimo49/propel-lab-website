# legacydram — AI駆動キュレーションメディア

## 概要

LLMエージェントによるウィスキーキュレーションメディアの自律運用プラットフォーム。蒸留所設計者・ブレンダー・所有者の決断を「他人のレガシーコードを読むエンジニアの視点」で読み解く人物軸キュレーションと、harness-opsによる自律コンテンツ生成（毎日EN/JAバイリンガル記事を自動投稿）を組み合わせた、深さで戦うニッチメディア。

第二弾（mypcrig.comに続く）として「legacydram.com」を運用中。広告コピー禁止・「ベスト◯選」listicle禁止・スポンサード記事禁止の編集方針で独立メディア性を保ち、Amazonアソシエイトを含むアフィリエイトを収益化のサブストリームとして組み込む。

## 対象

ウィスキー愛好者、エンジニア視点で趣味を深掘りしたい人

## 技術スタック

- LLMエージェント（Claude Code + harness-ops）
- context-forge人物・銘柄ナレッジDB（決断者の経歴・蒸留所の意思決定履歴）
- Astro v6 + Tailwind v4 + GitHub Pages（コンテンツ基盤）
- EN（一次）/ JA バイリンガル + hreflang
- Amazonアソシエイト（アフィリエイト自動化）

## 特徴

- 「銘柄リスト」ではなく「誰のどんな決断で生まれたか」から読み解く人物軸キュレーション
- 3カテゴリ（People / Craft / Tasting）を独立連載ではなく同視点の3つの角度として運用
- Tasting記事は必ずPeople + Craft要素を埋める編集ルールで質を担保
- mypcrigと同じ「興味起点 × LLMO × harness-ops 自律PDCA」テンプレートを別ジャンルへ横展開
