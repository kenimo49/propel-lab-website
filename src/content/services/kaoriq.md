# KaoriQ — AI駆動EC自動運用

## 概要

LLMエージェントによるECサイトの自律運用プラットフォーム。コンテンツ生成・SEO・LLMO最適化・商品キュレーションを完全自動化し、人手を最小限に抑えたEC運営を実現する。

第一弾としてフレグランス（香り雑貨）ECサイト「kaoriq.com」を運用中。性格診断 × 59,000本の香水データベースによるパーソナライズド推薦と、harness-opsによる自律コンテンツ生成（毎日EN/JAバイリンガル記事を自動投稿）を組み合わせた、仕組みで回るEC。

## 対象

EC事業者、D2Cブランド運営者

## 技術スタック

- LLMエージェント（Claude Code + harness-ops）
- Shopify Storefront / Admin API
- LLMO（Large Language Model Optimization）
- GA4 Data API（自動パフォーマンス観測）
- Astro + GitHub Pages（コンテンツ基盤）

## 特徴

- 記事の企画→執筆→品質チェック→公開→効果測定をすべてAIが自律実行
- カテゴリ別スキル（Guide / Science / Story）で読者層に応じた文体を自動切り替え
- 文化適応型ローカライゼーション（翻訳ではなく、市場ごとにデザイン・コンテンツを最適化）
- Shopifyドロップシッピングとの連動で在庫リスクゼロの運営
